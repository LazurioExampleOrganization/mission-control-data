# Roadmaps

Roadmap YAML files (`RM-XXXX`) of Lazurio Example Organization live here, in
`roadmaps/<year>/`.

Roadmaps follow `schemas/mission-control-roadmap.schema.json` and the roadmap
model of the upstream [Lazurio/mission-control](https://github.com/Lazurio/mission-control)
(`docs/roadmap-planning-model.md`):

- Roadmap Priority records explain the ranked intent.
- Roadmap Step records route execution and declare whether they are
  executable.
- Done steps need evidence references.
